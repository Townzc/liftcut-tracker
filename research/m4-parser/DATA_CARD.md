# M4 句子解析数据卡（v1）

用途：训练与评测端侧“一句话记录”解析模型（方案第 4 节 M4）。模型读一句训练原话和本次训练的动作名，输出 `@liftcut/core/parse-label` 定义的标签 v1；组号、记录 ID、公斤换算由确定性代码按会话解析，模型不负责。每条还带一个与句子相符的会话状态（每个动作已完成 `done` 组、计划 `setCount` 组：被更正的组已存在，被跳过的组尚未记录），供评测时把“最后一组”“下一组”解析成组号。

## 来源

- **全部合成**，不含任何真实用户或健康记录。先按分布抽取结构化标签，再用模板渲染句子（`src/synth.ts`，固定种子）；没有任何模型或解析器给句子打标签。
- 动作名来自项目自有的 60 个动作目录；数字有阿拉伯数字、口语中文（“一百二”“六十二点五”）和英文数词；单位 kg/公斤/千克/kilos、lb/磅/pounds，另有“斤”作为应追问的单位。
- 模型改写（DeepSeek）尚未加入；加入时只保留通过同一确定性校验的句子，并在此记录过滤率（M4-1c）。

## 规模与划分（`data/manifest.json` 为准）

| 集合 | 条数 | 说明 |
| --- | --- | --- |
| train | 4000 | 96 个训练模板；同一句最多重复 3 次（“收工”这类固定短语） |
| dev | 500 | 与 train 同模板、不同取值，句子互不重复 |
| test | 500 | **只用 41 个留出模板**，训练时从未见过这些句式 |
| handwritten | 60 | 手写自然口语，含干扰数字（“是 6 个不是 8 个”），**只做评测** |
| 150 条规则评测 | 150 | `packages/core/src/eval/workout-log-corpus.ts`，**只做评测** |

意图分布（train）：记录 1866、追问 1252、更正 454、跳过 189、同上 144、结束 95；语言：中文 2188、英文 1429、中英混杂 383。追问占比约 31%，是有意为之：编造次数为 0 比覆盖率更重要。

## 过滤与校验

- 每条都必须通过标签 schema、`labelTextProblems`（标签中的每个数字都在句中，句中没有多余数字，单位一致）以及“动作在本次训练列表里”。任何一条不通过即构建失败，因此放行的不一致标签为 0。
- 去重：train 渲染 4246 句，丢弃 246 句（超过重复上限或与评测集同句）；dev 513→500；test 514→500。
- 评测文本（test、dev、手写、150 条）按规范化文本精确排除在 train 之外，由 `tests/m4-synth.test.ts` 检查。

## 局限

- 模板句式比真实口语整齐；没有语音转写错误、错别字和长段闲聊。
- 精确排除不排除近义改写：“结束训练”与“结束今天的训练”这类固定短语在 train 和评测集之间可能只差几个字。
- 重量范围按器械粗略设定，不代表真实训练负荷；英文 “one” 作代词时会被当作数字 1，模板避开了这种句式。

## 复现

```sh
npm run m4:data             # 写 research/m4-parser/data/generated/*.jsonl（不入库）和 data/manifest.json
npm run m4:data -- --check  # 重新生成并核对哈希
```
