## 定位到的问题与被排除的改法

- 所有740条dev都来自训练已有模板；新challenge使用32个留出模板，但仅覆盖record/clarify。新HF dev737/740，challenge205/240（字面标签198/240），模板外泛化不足。旧test和手写已用于诊断，不能重新称独立盲测。
- HF challenge出现15条非法澄清原因、8条多生成组、12条应追问却尝试动作；分类按行且可重叠，与77个多填字段不能相加混用。例：一组“哑铃卧推11次，20lb”输出两组；未来目标被输出为不存在的target_not_actual原因。
