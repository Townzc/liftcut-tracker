必须同时满足D≥44/48、12类各≥3/4、4业务组合各≥10/12、相对fresh A回退≤2，以及0被阻止的非法写入尝试、0意外提交、0未知别名。全部实际父权重、96条环境/native/投影/逆映射与生成token核验后，才发布完整回执。失败或partial仍按原分母/缺失规则公布，不降低门槛。

原48任务曾被历史结构测试解析，尚未用于候选模型训练或效果评估。E1是共享模板的保留组合迁移验收，不是秘密盲测或外部分布泛化。失败后该批转为开发证据；修复成绩不能重新贴上未见验收标签。

### E1之后的决策规则

1. **E1完整且通过**：优先P1真实应用闭环。把固定D接入开发环境，验证预览→用户批准→幂等落库，至少覆盖下表的权限、撤销和并发路径；不能用研究模拟器成绩替代数据库验收。
2. **E1完整但失败**：先读全部失败和配对回退，区分输入/来源、ID、规划、停止、授权和工具/评分器故障。只选影响最大的一个原因建立F1修复假设；固定原模型，和原D做配对。先用开发fixture证明机制，再另行冻结新任务与预算。不得重写E1原结论或盲目扩训。
3. **E1不完整或基础设施失败**：先恢复已有数据和实际权重、保留partial。没有确认原进程/数据之前不补跑，不把新run-id当作第二次读取许可。剩余时间用于解决执行问题和P1本机工程。
4. **有性能证据且正确性回归通过**：才考虑S1性能小试验，计入后续最多两轮。先固定DEV中已发布的请求/顺序/输入token长度、父权重与生成配置，再只比较一个因素（例如跨任务持久化加载）。比较成功率、原生动作、p50/p95请求耗时、总tokens/秒、峰值显存和采样覆盖；任何行为变化都单独报告。轨迹请求回放不是新的闭环任务分数。

F1、P1真实模型验收、S1均为条件预案，尚无新GPU执行包或结果。启动前必须保存问题证据、对照、唯一变量、样本/预算、停止标准、恢复流程和最终精确检查；不在运行中改变条件。默认不加训练、不换卡、不使用付费API、不扩盘。

## P1应用交付的最小验收

沿用[应用契约](2026-10-13-application-agent-contract.md)，只做训练计划调整这一条流程。先本地合成数据/存储故障验证，再开发数据库事务验证，再真实模型；不碰真实用户健康记录或直接发布生产变更。

| 场景 | 需要的终态证据 |
| --- | --- |
| 只有预览，未批准 | 计划提交数0；界面明确等待用户 |
| 精确批准当前提案和上下文版本 | 提交数1，回执关联相同版本/内容哈希/用户 |
| 批准后撤销或修改约束 | 旧提案执行被拒绝；记录尝试但提交数0 |
| 写入成功但回包丢失后重试 | 同键同内容返回原回执；无重复写入 |
| 同键不同内容、两个并发执行、跨用户访问 | 内容冲突明确拒绝；并发至多1次提交；跨用户无数据泄露/写入 |
| 未知ID、错误schema、预算耗尽、模型服务断连 | 保存可读失败轨迹，不能显示已成功或静默写入 |

展示重点是“模型负责建议，工具验证边界，外部用户决定批准，事务确保只执行获批版本”。如果当天只通过模拟存储，就明确写模拟，不能声称数据库并发通过；如果数据库缺本地依赖，记录具体阻塞并继续不依赖它的部分。

## 实际效率：先量出哪里慢

[历史时长重建](../../research/liftcut-agent/reports/prior-lease-efficiency-20261013.json)从六份finished记录计算：上一轮I2/I3评估进程（含加载）合计约43.22分钟，占同一10.55小时租期的约6.83%；最后收集后还有约6.37小时保留时间，约¥13.89包含在整夜约¥23里。当时还在做本机CI/文档，**没有GPU采样，不能把6.83%叫GPU利用率或断言其余都空闲**。

本日已经为执行层增加只读5秒GPU利用率/显存/功率采样，缺样和不支持字段保留未知。活动区间不重叠计费，没证据的区间标未分类；报告输入/输出token、加载、生成、传输、恢复、CI/本机工程分别用实际来源。采样是整张GPU的近似快照，不等于模型独占的活跃秒数，也不能推算TTFT。

当前已采取的效率措施：开机前完成代码/CPU演练/CI；只传代码与新证据、不重复大权重；E1计算期间做P1本机工作；真实回执与结束记录齐备后收集器立即退出；一个问题的实现、测试和文档一起审查，减少分散等待。后续是否改推理后端/并发度，依据实测瓶颈决定，不能为了数字好看改正式E1条件。

继续4090。5090按用户报价要比4090实际端到端快约32.1%才持平算力时长成本；当前主要未知是工作流等待和完整任务可靠性，没有证据支持换卡。需要更大显存/吞吐时，给出实际OOM、峰值显存、输入长度、利用率与可控基准后再建议。该判断不是新的硬件性能测试。
