# 90 秒产品演示脚本（待录制）

使用专门合成账号，先建立一日三组卧推计划。不得录制维护者真实健康数据。本文件是脚本，不是已录制视频或真机测试结果。

| 时间 | 操作 | 展示的事实 |
| --- | --- | --- |
| 0–10 秒 | 首页 → Agent | 黑白页面、底部仅首页 / Agent / 设置，补录默认折叠 |
| 10–25 秒 | 输入「记下体重 72.5 公斤」，确认，再问「最近体重」 | 草稿只填明确数值，腰围空白，确认后可以查询 |
| 25–40 秒 | 输入「记录午餐 鸡肉饭」，确认，问「今天吃了什么」 | 不凭食物名称估算热量，未记录不等于没吃 |
| 40–55 秒 | 展开回执来源，再撤销补录 | 原话和时间可追溯；撤销是补偿，历史保留 |
| 55–75 秒 | 开始训练，断网，输入「杠铃卧推 8、7 次」，确认后恢复网络 | 已载入页面继续入队，补发后只保存一次，重量和 RPE 为空 |
| 75–90 秒 | 展开一组来源，查看事件，切换设置深色模式 | 真实状态变化可检查，统一黑白与灰色主题 |

讲解边界：当前是规则与已存数据模式。自动浏览器故障注入已验证，手机宽度桌面 Chromium 不等于手机真机；关闭页面或离线冷启动不在承诺范围。
