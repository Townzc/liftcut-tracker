# 开放式 Agent 对话

2026-10-14。用户明确要求继续接入开放式模型对话，测试后上线。本轮沿用既有 DeepSeek 配置和黑白三入口，不新开研究/GPU，也不添加长期记忆系统。

- 自然语言 → 本人认证 → 有限工具循环 → 按需读取最新记录 / 生成草稿 → 来源和确认卡。
- 模型只选择工具与原话片段。数值、单位换算、日期、当前组定位由代码验证；未报告值保持 null。计划与实际分开展示。
- 身体、饮食、当前训练记录/次数更正共用既有写入队列；服务端签名绑定本人、UUID、原话、不可变草稿和上下文。确认才写入，幂等重试、补偿撤销继续成立。
- 仅发送当前任务所需数据，启用前告知模型接收方并单独同意；最近六轮用于追问，本标签页会话可清空，不保存为长期记忆。模型生成回复带标识。
- 有限调用步数、输出、数据范围、每账号频率/日额度；超时、取消、读取失败、配额耗尽明确展示，不假装成功或空历史。
- 必须覆盖：实际模型查询/多轮/补录；未经确认零写入；伪造草稿、越权、未知营养、目标冒充实际、旧上下文、响应丢失与离线、工具/模型失败。CI 使用明确标识的脚本模型，真实 API 验收单独留证。
- 发布：最终精确提交通过完整 CI，增量迁移/受限权限、正式域名验收、仅清理合成账号与数据，保留原有业务记录。

技术依据：安装的 AI SDK 7.0.140 文档与源码；[DeepSeek 官方模型页](https://api-docs.deepseek.com/quick_start/pricing/)；[Supabase RLS](https://supabase.com/docs/guides/database/postgres/row-level-security)。官方当前 Flash 名称为 `deepseek-flash`，已有 `deepseek-v4-flash` 为兼容别名，新对话使用当前名称。
