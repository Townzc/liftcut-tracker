# C1：可互动的训练助手界面

2026-10-14，维护者要求尽快提供可亲自互动的 Agent 交谈界面。在已上线 W1–W3 的基础上，将对话入口前置；不改研究路线和冻结结果，也不把第 4 周完整轨迹查看器视为已完成。

## 为什么先做这一段

记录、草稿、补偿、替换和离线事务已经实际验证。现在需要一个集中交谈入口，让用户试用这些能力并提供反馈。新界面复用同一个 TodayWorkspace 和发件箱，不建立第二套写入服务。现有非 eve 技术栈继续使用，避免为聊天界面重建账本。

## 本次范围与验收

- 新 `/coach`，登录与今日卡功能开关一致；主导航和今日卡可进入。
- 明确标注本机规则模式。只处理训练记录、次数更正、跳过、结束、当前计划/进度查询、替换入口和回执入口；未调用自由问答模型，不冒充模型生成。
- 对话含用户消息、助手回应、明确的澄清、内联草稿/确认/取消和当前动作选择。缺动作时可选择动作继续解析同一句，不自动猜测实际数值。
- 查询只读取当前会话投影，注明含待同步内容和读取时点；计划始终是目标，不是实际。
- 一次只保留一个有效草稿；新消息关闭旧草稿。上下文更新或切换训练后不能确认旧草稿，必须明确重新生成并再次确认。
- 确认走原 UUID/上下文/版本/IndexedDB 发件箱。只有持久化成功才提示进入同步队列，未得到云端回执不能显示云端保存成功。
- 补偿撤销、替换的设备冲突、账号隔离和重试使用已有组件/服务；不改长期计划，不新增 DB 权限或迁移。
- 聊天文字暂存本页，刷新/离开后不保留未提交聊天。已确认的记录、原话与回执沿原链路恢复；界面明确区分两者。不新建通用长期记忆。
- 双语、键盘 Enter 发送/Shift+Enter 换行/中文输入法组合态不误发，手机宽度无横向溢出。
- 验证纯意图分流、浏览器→真实 API→本地 PostgreSQL（含离线与旧草稿），最终全部检查后合并。正式部署再用合成账号做真实 Auth/写入/回执/清理，保留真实结果。

## 当前边界

自由问答/模型解析、语音、完整跨页面聊天历史、离线冷启动、真机微信仍不在本次已完成范围。模型能力接入仍遵守产品方案中的访问控制、单独数据告知与适用手续；本片段没有模型费用或 GPU 需求。真实执行与发现写入独立验证记录，不能提前填写成功。
