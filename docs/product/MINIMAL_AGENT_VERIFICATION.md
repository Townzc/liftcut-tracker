# 三栏黑白界面与统一数据助手：验证记录

2026-10-14。依据 [任务范围](MINIMAL_AGENT_BRIEF.md) 实现；分支基于 `d01b1fd`。下述本地结果已发生，发布状态单独核对，不把计划当作上线结果。

## 设计选择与结果

1. **为什么收敛入口**：维护者明确要求简洁黑白、首页 / Agent / 设置。移除侧栏与多模块主导航，使用中性灰、留白、三项底栏；登录页同步简化。首页只保留对话入口、查询提示和折叠补录；设置把详细资料折叠，常用语言/主题/导出可直接访问。
2. **为什么增加可空账本**：旧饮食表的完整数值结构不能安全承接「只说食物名称」。新 `personal_record_events` 保存严格校验后的身体/饮食新增和补偿，未知值为 NULL；不推算、不改写旧历史。手动与对话共用同一 API，服务端对对话原文重新解析并核对草稿。
3. **为什么持久化请求**：网络失败不能证明未提交。账号分区本机请求键保存原 UUID 和原字节，跨页/刷新可重试；存储失败零发送。服务器本人 RLS、事务锁、内容摘要和唯一补偿确保重复请求不多写，迟到创建不能复活撤销记录。训练仍沿用原 IndexedDB 有序发件箱。
4. **为什么查询注明边界**：读取失败、空记录和真实 0 不是一回事。Agent 按日期合并本人旧历史与新补录，排除撤销项，标明营养部分合计；目标查询不返回实际值，加载/离线时不把未知历史说成无记录。身体与饮食查询不要求先开始训练。
5. **为什么加入来源查看**：推进 W4 的可解释交付。训练组新增按本人读取的版本/事件/原话面板；个人回执可看来源与补偿时间。只展示输入、输出和状态，不展示模型推理。导出 JSON 含新补录及撤销历史。

## 实际验证

| 检查 | 结果 |
| --- | --- |
| 单元测试 | 80 通过（7 mjs + 73 TypeScript）；新增严格解析、缺失/零值、目标区分和撤销查询检查 |
| 真实 PostgreSQL | 新的一次性本地库从实际 W1a schema 升级，31 测试通过（8 + 9 + 1 + 9 + 4）；包含来源隔离、幂等并发、补偿、NULL、权限 |
| 浏览器 | 最终完整 35 场景通过，1.4 分钟；真实 Next/API/PG，登录服务为本地 HTTP 契约替身 |
| 构建与类型 | Next 生产构建和 TypeScript 通过；新增 `/agent`、个人补录 API 和来源 API |
| lint | 0 错误，研究脚本原有 2 警告 |
| 视觉 | 实际查看手机首页、Agent 数据回执、桌面 Agent、黑白登录与深色设置截图；无横向溢出 |

新增浏览器验收覆盖：首页双击保存 → 刷新 → Agent 查询 → 撤销 → JSON 导出；食物缺营养 → 提交后丢响应 → 跨页重试一次 → 来源恢复；首页查询预填不自动执行、键盘发送、手机/桌面/深色、账号切换；断网补录 → 联网一次提交；localStorage 拒绝时零请求。另验证匿名、跨来源、账号不匹配和功能关闭拒绝写入。

所有原训练、整句更正/补偿、动作替换、离线顺序和账号恢复场景一并回归。移除了一项要求旧首页多个模块链接的源码正则断言，改由真实浏览器验证三栏产品行为；没有删除业务数据验证。

## 发现与修正

- WSL PostgreSQL 在启动服务后随发行版退出，造成连接拒绝；保留单独本地进程后恢复测试。数据库测试器拒绝复用旧库，最终另建空库从原始 schema 升级。
- 首轮重点浏览器 7/8：旧场景直接寻找折叠区内的开始按钮；调整为先展开，再验证真实动作。初版桌面截图曾截到加载态，补上页面就绪条件后重拍并实看。
- 首轮全回归 34/35：原英文替换测试仍寻找已移除的 Today 主导航。改由 Agent → 详细训练卡，保留动作身份、长期计划和补偿断言；最终 35/35。
- 收尾检查修复设置保存按钮分组、目标查询误入实际值分支，以及历史不可读时的提示。导出验证同时检查 NULL 和撤销状态，避免只证明成功下载。

## 发布与后续边界

此实现提交的精确 CI、增量迁移、生产部署及真实 Auth 验收另行执行；必须核对 8 项检查、受检/合并树、Vercel 正式别名、独立 SQL 和精确合成账号清理。迁移只加新账本，不改已有记录。最终发布观察放入本地交接及 PR 描述，避免为记录合并事实循环发布代码。

当前为规则数据助手，没有自由模型问答、跨页聊天历史或营养推算。旧 `/body` 和 `/nutrition` 深层页面仍只读旧数据，新补录通过 Agent / 回执 / JSON 导出访问。体重更正用撤销后重新填写；离线限已载入页面，本机存储可被清理，不承诺离线冷启动或后台发送。W4 已推进组来源查看、工程问答和演示脚本；正式录屏、真机微信/iOS/Android 仍待独立完成。本轮不需 GPU，也没有模型调用。
