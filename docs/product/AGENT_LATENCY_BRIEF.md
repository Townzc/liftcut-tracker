# Agent 分段计时与查询提速

2026-10-14，接续 [流式回复](AGENT_STREAMING_BRIEF.md)。不增加常驻 UI；修改仍经完整草稿和明确确认。

## 计时口径

每个请求使用同一单调时钟。JSON 及流式终态带 `timing`；常规界面不展示这些开发诊断字段。日志仅记录数字、固定操作名称和请求 ID，不记录原话、SQL、工具数据、密钥或模型错误正文。

- `authMs`：服务端验证身份；`quotaMs`：原子限额预留，包含受限数据库连接、事务和锁。
- `model[]`：每轮完成的模型调用、首个输出片段、HTTP 响应头、输入/输出及缓存命中 token。首个模型片段可能是工具参数，不能当作用户首字。中断的模型轮次没有完成事件，不能把缺失指标当成零耗时。
- `tools[]`：工具从开始到完成的区间，含必要的顺序等待。`toolWallMs` 为区间并集，不能把同时运行的工具耗时相加。
- `database[]`：记录查询/限额的连接、初始化、SQL 工作和提交；计划与当前训练使用工具总耗时。连接耗时包含池等待和建立连接；SQL 工作包含往返、锁等待和执行，不等于数据库纯 CPU 时间。
- `firstTextMs`：可向客户端发送的首段回答；`serverMs`：从进入路由到结果完成。草稿只在完整校验后出现，因此其文字首段为 null。
- `Server-Timing`：鉴权与流响应准备。浏览器实际 `reader.read()` 记录响应头、首段、结束，同时观察 DOM。客户端完整时间减 `serverMs` 仅估计浏览器至平台往返/调度/传输余量，不把它冒充纯网络 RTT。

提供方响应头和首个输出的等待都可能包含网络、排队、推理。外部 API 没有提供内部阶段时间，因此无法精确分离模型纯计算与提供方网络。已有连接池、同区域部署与提供方前缀缓存继续使用，没有通过缓存旧健康记录提速。

## 改动与确认边界

1. 日期、记录主题和查询意图都明确时，服务端先读取本人新鲜记录，将实际工具结果交给模型直接回答。支持今天/昨天/前天、本周、过去 7/28 天的身体、饮食、训练查询。比较、复杂时间、修改意图、引用内容和含糊追问继续由模型选工具。模型仍可补读缺失主题；同请求相同查询去重。
2. 继续使用 AI SDK `ToolLoopAgent`。独立 `read_records` / `current_workout` 可重叠执行，SDK 并发上限 3，数据库池仍为 4；同一 pg client 内没有并发 query。批量主题原本就并行，本轮增加的是独立工具调用间的并行。
3. 草稿、最终回答和计划上下文使用先来先服务的屏障。最终文字不能抢在待完成的查询前流出；两个准备工具不能同时创建两份草稿。计划上下文可能标记过期账本，故不作为纯只读操作并行。
4. 事务初始化从 5 次往返减为 2 次，只合并固定 SQL；受限角色每次检查，用户 subject 仍绑定参数且仅在事务内有效。限额仍持有账户锁；所有批准、版本、幂等、撤销检查保留。无迁移或权限提升。
5. 当前训练只读取活动会话与其实际组/替换，不再加载页面所需的日期选项、完整回执和往期最佳值。

## 本地实测

真实 DeepSeek、独立合成账户、同一本地 PostgreSQL、空历史。基线先加入计时，尚未启用优化；不是线上/国内网络/P95 或固定输出基准。

| 相同场景 | 基线首段 / 完成 | 优化第 1 轮 | 优化第 2 轮 |
| --- | --- | --- | --- |
| 普通介绍 | 3703 / 4869 ms | 3403 / 4505 ms | 3682 / 4730 ms |
| 最近一周身体+饮食 | 5659 / 6180 ms | 2848 / 3284 ms | 2585 / 3047 ms |
| 身体草稿完整可确认 | 3120 ms | 3194 ms | 3012 ms |
| 两天训练计划完整预览 | 9477 ms | 8389 ms | 9855 ms |

双主题查询从 2 轮模型调用降到 1 轮；基线模型合计 6136 ms、工具 21 ms，优化首轮模型 3252 ms、预读 15 ms。主要收益来自少一次模型调用。不能据这个样本宣称全部场景都更快。

数据库故障测试持有身体表锁，证明饮食查询已完成时身体查询仍被阻塞，同时没有提前输出最终回答；解锁后两个来源齐全。另覆盖重复草稿、失败释放、取消、角色拒绝、池连接用户上下文清理与当前训练一致性。来源、未知值、确认前零写入、双击幂等、停止/断流和跨账号回归保持。

最终测试输出见 [证据索引](evidence/coach-latency/verification.json)。精确 CI、正式部署及正式站同提示词前后测量在发布交接中记录，不能把本地通过当作已经上线。
