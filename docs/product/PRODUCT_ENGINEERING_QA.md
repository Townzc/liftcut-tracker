# 当前产品工程问答

2026-10-14。本页只描述当前实现；历史模型训练结果见原研究报告，不把规则解析成功当作模型泛化能力。

## 为什么首页不再摆满统计卡片？

维护者反馈原导航和模块过多。主要任务是记录和查询，所以主导航收敛为首页、Agent、设置。首页保留可展开的补录，Agent 统一读取训练、饮食和身体历史；详细训练和计划工具按需打开。减少入口并不删除已有用户历史。

## Agent 现在到底能做什么？

单独同意后，当前对话层接入 DeepSeek 开放式对话，可以理解自然表达和最近六轮追问，按需读取本人最新身体、饮食、训练、计划和目标数据。模型只产生解释或草稿；数值必须来自用户原话片段，经代码校验、签名绑定和用户确认后，才能进入原有写入队列。未同意或离线时，明确句式仍走本机规则。它不会估算缺失的营养值或用目标 RPE 填实际记录。

## 为什么用工具循环和签名，而不是让模型返回一段 JSON 就保存？

工具只允许有限范围的本人读取、草稿准备与回复，没有 SQL 或写入工具。AI SDK 负责最多五步的调用循环；本人权限、日期、数值、单位、组位置、版本和幂等都由服务端校验。签名绑定账号、UUID、完整草稿、原话和七天有效期；修改内容会失败。已提交请求在签名到期后仍能按原字节取回同一回执，不能再次生效。来源保留本次原话和实际采用的片段，不把整段聊天永久保存。

## 如何区分模型演示与自动回归？

CI 的模型是明确标注的脚本 HTTP 替身，验证工具契约、页面到 API/真实数据库、拒绝路径和故障恢复。另有显式启用的真实 DeepSeek 评测，只发送合成数据，记录实际模型、工具调用、延迟和结果。两者分别列在 [模型对话验证](MODEL_CONVERSATION_VERIFICATION.md)，不把脚本命中率说成模型泛化能力。

## 断网与请求结果未知有什么区别？

断网时，操作先写入本机持久化队列；存储失败则不发送。响应丢失时，服务器可能已经提交，因此重试必须保持 UUID 和请求内容不变。数据库返回同一回执；改变内容的同 UUID 请求会被拒绝。训练请求还有顺序、版本和上下文保护；独立的身体/饮食新增记录不互相依赖，使用按账号分区的独立请求键。

## 为什么撤销不直接 DELETE？

删除会抹掉原话和发生过的事实，也无法解释迟到重试。补偿事件保留原记录，查询投影排除已撤销项；同一撤销重复提交返回原回执，迟到的创建重试不能让它重新生效。受限运行账号没有新账本的 UPDATE/DELETE 权限。

## 如何证明“没编造”而不仅是界面显示为空？

同时检查解析预期、HTTP 请求、真实 PostgreSQL 中的 NULL 和导出结果。计划字段与实际字段分开；身体目标查询不冒充实测数据，食物未知营养不补零。测试包含另一个账号、负向权限、响应丢失、明确的 0、撤销后重试和本机存储故障。自动测试使用人工合成数据；没有临床有效性或任意口语泛化结论。

## 为什么保存成功后查询仍要重新读取？

保存回执和页面缓存刷新不是同一个完成点。真实托管验收曾出现训练已结束而 Agent 回答 0 次；现在查询会等本人历史的最新读取，读取失败或离线不冒充空记录。回归测试刻意挂住后台刷新，独立确认服务器已保存，再要求 Agent 答出最新次数。详见 [查询新鲜度验证](AGENT_QUERY_FRESHNESS.md)。

## 轨迹查看器展示什么？

组记录可展开版本、写入事件、实际值和确认原话；个人补录显示输入方式、保存时间、原话及补偿撤销时间。接口按真实登录账号及 RLS 读取，不依赖客户端传来的用户 ID 授权。它展示输入和状态变化，不展示模型推理。

## 还没完成什么？

真机微信/iOS/Android、离线冷启动、关闭页面后的后台发送和跨页面聊天历史尚未完成。自然对话已接入；训练补录仍需先开始当前会话，一次确认一条身体/饮食记录或一个动作的组记录，复杂含糊语句会追问。长期计划仍走已有批准流程。[90 秒界面演示](MINIMAL_AGENT_WALKTHROUGH.md) 使用合成账号，录制于模型接入前。旧身体/饮食详情页仍只展示旧存储，新的可空补录在 Agent 与完整 JSON 导出中查询；不把缺失值映射回旧表的非空字段。
