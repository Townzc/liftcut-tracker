## 简历价值与写法

适合定位为 **面向真实部署的 Agent 应用工程项目**。可讲清的难点包括工具权限与数据可信度、流式交互、事实检索、带版本的人工批准、数据库事务与重试恢复。现有证据比“接一个聊天 API”更充分，但项目亮点取决于能否解释设计取舍、现场演示与复现失败路径。

可以据实表达：

- 构建 Next.js / TypeScript / PostgreSQL 健身 Agent，统一查询、补录及训练/饮食计划生成与局部调整，模型通过受限工具读取数据，所有变更经用户确认。
- 设计按日期和来源组织的结构化健身记忆及提案依据快照；在发布、批准、执行时校验事实，结合 RLS、事务锁、幂等键及补偿事件处理跨账号访问、并发变更和丢响应重试。
- 建立真实 PostgreSQL 与浏览器回归，分开报告脚本模型契约测试和真实模型调用；验证后通过 CI 与正式域名部署验收。

不应写成大规模商业上线、已验证减脂增肌效果、任意表达理解率、生产 SLA，或把历史研究结果描述为本产品在线模型训练收益。测试数字须注明日期、环境和合成数据范围，见 [本轮证据](PLAN_MEMORY_VERIFICATION.md)。
