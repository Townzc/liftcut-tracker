## 后续追加的转型目标

- 三入口和黑白简洁 UI 已上线：首页保留补录，Agent 常驻对话框，设置为分组子页面；训练、饮食、身体能力收进对话。
- 开放式模型问答、每次查新鲜记录、身体/饮食/训练草稿已上线。训练与饮食计划的生成、局部调整、完整预览、明确确认、回执与恢复均已接入 Agent。
- 真实增量显示、停止、断流丢弃、输入框不等待全量历史已上线。本轮进一步加入 [分段计时、明确查询少一次模型调用、独立只读工具并行](AGENT_LATENCY_BRIEF.md)。
- 模型可用 10 个有限工具：记录查询、当前训练、计划上下文、身体/饮食/训练草稿、训练/饮食计划预览、计划局部调整、最终回答。模型没有批准、执行、直接 SQL、任意删除或跨用户查询工具。
- 聊天上下文为当前页面最近 6 个完整轮次；未完成回答不进入历史。长期事实来自本人结构化记录、设置、计划及批准账本，随问随读；没有通用长期记忆或向量库。

目前已从“模块入口迁移、补齐 Agent 能力”进入“响应速度、实际使用与演示收尾”。下一步优先验证国内真实设备/网络、观察真实使用中的查询耗时和误解析，再更新当前版本演示；不会为了转型增加多 Agent 编排或新模型训练。
